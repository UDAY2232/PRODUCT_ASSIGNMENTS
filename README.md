1. DSA Assignments

Assignment areas currently captured:

Array / Two Pointer practice – 10 LeetCode problems:

Remove Element, Reverse String, Merge Sorted Array, Sort Colors, Next Permutation, Find the Duplicate Number, First Missing Positive, Trapping Rain Water, Rotate Array, Pancake Sorting.

Running Sum of 1D Array, Range Sum Query – Immutable, Find the Middle Index in Array, Find Pivot Index, Subarray Sum Equals K, Contiguous Array, Continuous Subarray Sum, Matrix Block Sum, Number of Submatrices That Sum to Target, Count of Range Sum.

Binary Search, Search Insert Position, First Bad Version, Sqrt(x), Find First and Last Position of Element in Sorted Array, Search in Rotated Sorted Array, Find Peak Element, Search a 2D Matrix, Koko Eating Bananas, Median of Two Sorted Arrays.

Dynamic Programming practice – 10 problems:

Delete and Earn, Partition Equal Subset Sum, Target Sum, Minimum Cost For Tickets, Last Stone Weight II, Codeforces 455A, Codeforces 1195C, Codeforces 1097B, Codeforces 698A, Codeforces 1418C.

Additional DSA problems practiced: Codeforces C. Three Parts of the Array and C. Boats Competition.

3. SQL Assignments

SQL Assignment – 70 SQL interview/assignment questions based on Employee and Incentives tables.

Topics covered: SELECT, aliases, string functions, DISTINCT, ORDER BY, WHERE, LIKE, pattern matching, date functions, escape characters, GROUP BY, aggregate functions, HAVING, JOINs, subqueries, TOP-N salary, UNION/UNION ALL, EXISTS, CASE, DELETE, INSERT with special characters, ranking, and UPDATE.

Question 34 is missing from the supplied SQL PDF; numbering jumps from 33 to 35.

SQL JOIN Practice – 10 questions using departments, employees, projects, and employee_project tables.

JOIN practice topics: INNER JOIN, LEFT JOIN, finding departments without employees, multiple joins, projects with employees, self join for managers, employees with multiple projects, department statistics, cross-department project work, and projects with no assigned employees.
